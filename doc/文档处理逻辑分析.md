# Free-Markdown-Translator 文档处理逻辑分析

## 1. 项目整体架构

Free-Markdown-Translator 是一个基于 [Translators](https://github.com/UlionTse/translators) 库的 Markdown 文档翻译器。项目采用模块化设计，主要由以下几个核心模块组成：

### 1.1 核心模块

- **MarkdownTranslator.py**: 主要翻译器类，负责整体翻译流程控制
- **Translator.py**: 翻译执行器，处理实际的文本翻译和过滤逻辑
- **Nodes.py**: 节点系统，定义不同类型的 Markdown 内容节点
- **Utils.py**: 工具模块，包含正则表达式模式和辅助函数
- **config.py**: 配置管理模块

### 1.2 整体工作流程

```
输入 Markdown 文件 → 预处理 → 节点解析 → 内容过滤 → 分块处理 → 翻译执行 → 后处理 → 输出翻译文件
```

## 2. 过滤器系统详细分析

过滤器系统是项目的核心特性之一，确保在翻译过程中保持 Markdown 格式的完整性。过滤器系统主要分为三个层次：

### 2.1 正则表达式过滤器 (Utils.py)

#### 2.1.1 跳过翻译的内容模式 (skipped_regexs)

在 `Utils.py` 文件的第11-12行定义了需要跳过翻译的正则表达式列表：

```python
skipped_regexs = [
    r"\*\*。?",           # 加粗符号（**）
    r'#+',                # 标题符号（#）
    r'`[^\u4E00-\u9FFF]*?`',  # 代码块中的非中文字符
    r'`',                 # 反引号
    r'"[^\u4E00-\u9FFF]*?"',  # 引号中的非中文字符
    r'\|',                # 表格分隔符
    r'^ *-+',             # 列表分隔符
    r'^[\.,\?!;。，？！；、]$',  # 单独的标点符号
    '\n'                  # 换行符
]
```

#### 2.1.2 需要添加分隔的内容模式 (expands_regexs)

第14行定义了在非紧凑型语言中需要添加空格分隔的内容：

```python
expands_regexs = [
    r'`[^`]+?`',          # 行内代码
    r'".*?"',             # 双引号内容
    r'\*\*.*?\*\*',       # 加粗文本
    r"\[!\[.*?]\(.*?\)]\(.*?\)|!?\[.*?]\(.*?\)"  # 图片和链接
]
```

### 2.2 节点级过滤器 (Nodes.py)

#### 2.2.1 节点类型分类

项目定义了多种节点类型，每种节点都有不同的过滤和处理策略：

**TransparentNode (透明节点)**:
- 完全跳过翻译的内容
- 包括：代码块、Front Matter 中的技术字段、图片标签等
- `trans_lines = 0`

**SolidNode (实体节点)**:
- 需要完全翻译的普通文本内容
- 包括：正文段落、普通文字等
- `trans_lines = 1`

**KeyValueNode (键值节点)**:
- Front Matter 中的键值对，只翻译值部分
- 如：`title: 这里的内容需要翻译`

**TitleNode (标题节点)**:
- Markdown 标题，只翻译标题文本，保留标题符号
- 如：`# 标题内容` → `# Title Content`

**ImageOrLinkNode (图片/链接节点)**:
- 复杂的图片和链接处理，只翻译描述文本
- 保留链接 URL 和图片路径不变

**KeyValueArrayNode (键值数组节点)**:
- Front Matter 中的数组值，如标签和分类

#### 2.2.2 节点过滤逻辑示例

以 `ImageOrLinkNode` 为例，展示复杂的过滤逻辑：

```python
def __init__(self, line):
    # 提取所有图片和链接
    matches = Patterns.ImageOrLink.findall(line)
    # 分离文本片段
    self.__text_fragments = Patterns.ImageOrLink.split(line)
    
    for position, item in enumerate(matches):
        # 提取嵌套图片和描述
        nested_image, description = Patterns.DescOrNestedImage.findall(item).pop()
        # 提取链接
        link = Patterns.LinkContent.findall(item).pop()
        
        # 只保存需要翻译的描述文本
        self.__descriptions.append(description)
        # 保存不需要翻译的链接和图片信息
        self.__links.append(link)
    
    # 只翻译描述和其他文本片段
    self.value = '\n'.join(self.__descriptions + self.__text_fragments)
```

### 2.3 翻译级过滤器 (Translator.py)

#### 2.3.1 分块过滤机制

在 `Translator.py` 的 `__translate_with_skipped_chars` 方法中实现了最核心的过滤逻辑：

```python
def __translate_with_skipped_chars(self, chunk, src_lang, target_lang, pbar):
    # 分离跳过和需要翻译的部分
    skipped_parts, need_translate_parts, parts_count = chunk
    
    # 只翻译需要翻译的部分
    text_to_translate = "\n".join(need_translate_parts.values())
    translated_text = self.translate(text_to_translate, src_lang, target_lang)
    
    # 重新组装：保持跳过部分不变，替换翻译部分
    for position, key in enumerate(need_translate_parts.keys()):
        need_translate_parts[key] = translated_text[position]
    
    # 如果目标语言不是中文，转换全角符号为半角
    if not target_lang.lower().startswith("zh"):
        skipped_parts = {key: SymbolWidthUtil.full_to_half(value) 
                        for key, value in skipped_parts.items()}
    
    # 按原始顺序重新组装
    total_parts = {**skipped_parts, **need_translate_parts}
    return "".join(total_parts[i] for i in range(parts_count))
```

## 3. 文本处理流程详解

### 3.1 预处理阶段 (__preprocessing)

```python
def __preprocessing(self, src_file: Path) -> RawData:
    # 1. 读取文件内容
    src_lines = src_file.read_text(encoding="utf-8").splitlines()
    
    # 2. 生成节点树
    nodes = self.__generate_nodes(src_lines)
    
    # 3. 提取待翻译文本
    lines_to_translate = "".join(node.get_trans_buff() for node in nodes 
                                if node.get_trans_buff()).splitlines()
    
    # 4. 处理空行
    empty_line_position = [position for position, line in enumerate(lines_to_translate) 
                          if not line.strip()]
    lines_to_translate = [line for line in lines_to_translate if line.strip()]
    
    # 5. 分块处理（避免文本过长）
    chunks, buff = [], []
    length = 0
    for line in lines_to_translate:
        buff.append(line)
        length += len(line)
        if length > 500:  # 控制每次发送的数据量
            chunks.append(self.__handle_chunk('\n'.join(buff) + '\n'))
            buff.clear()
            length = 0
```

### 3.2 分块处理 (__handle_chunk)

这是过滤器系统的核心方法：

```python
@staticmethod
def __handle_chunk(chunk: str) -> tuple[dict[int, str], dict[int, str], int]:
    # 使用正则表达式分割文本
    parts: list[str] = Patterns.Skipped.split(chunk)
    
    skipped_parts: dict[int, str] = {}      # 跳过的部分
    need_translate_parts: dict[int, str] = {} # 需要翻译的部分
    
    position = 0
    for part in parts:
        if len(part) == 0:
            continue
        # 判断是否匹配跳过模式
        if Patterns.Skipped.search(part):
            skipped_parts.update({position: part})
        else:
            need_translate_parts.update({position: part})
        position += 1
    
    return skipped_parts, need_translate_parts, position
```

### 3.3 节点生成逻辑 (__generate_nodes)

```python
def __generate_nodes(src_lines: list[str]) -> list[Node]:
    is_front_matter = False
    is_code_block = False
    is_not_trans = False
    nodes = []
    
    for line in src_lines:
        # Front Matter 检测
        if line.strip() == "---":
            is_front_matter = not is_front_matter
            nodes.append(TransparentNode(line))
            continue
        
        # 代码块检测
        if line.startswith("```"):
            is_code_block = not is_code_block
            nodes.append(TransparentNode(line))
            continue
        
        # 自定义不翻译标记
        if line.startswith("__do_not_translate__"):
            is_not_trans = not is_not_trans
            continue
        
        # 根据当前状态选择节点类型
        if is_front_matter:
            # Front Matter 内容分类处理
            if line.startswith(tuple(config.front_matter_key_value_keys)):
                nodes.append(KeyValueNode(line))
            elif line.startswith(tuple(config.front_matter_transparent_keys)):
                nodes.append(TransparentNode(line))
            # ... 其他 Front Matter 处理
        elif is_code_block or is_not_trans:
            nodes.append(TransparentNode(line))
        else:
            # 普通内容处理
            if len(line.strip()) == 0 or line.startswith(("<audio", "<img ")):
                nodes.append(TransparentNode(line))
            elif Patterns.ImageOrLink.search(line):
                nodes.append(ImageOrLinkNode(line))
            elif line.strip().startswith("#"):
                nodes.append(TitleNode(line))
            else:
                nodes.append(SolidNode(line))
```

## 4. 后处理和优化

### 4.1 语言特定处理

项目针对不同语言特性进行了优化：

#### 4.1.1 紧凑型语言处理

对于中文、日文等紧凑型语言，不需要添加额外空格：

```python
# 配置中的紧凑型语言
compact_langs = ['zh-TW', 'ja']

# 处理逻辑
if target_lang in config.compact_langs:
    markdown_result.append(translated_line)
    continue
```

对于英语等非紧凑型语言，需要在特定位置添加空格：

```python
parts = Patterns.Expands.split(translated_line)
line = "".join(expand_part(part, parts, position, last_char) 
               for position, part in enumerate(parts))
```

## 5. 过滤器系统的优势

### 5.1 精确的格式保护

- **多层级过滤**: 从正则表达式到节点类型再到翻译级别的三重过滤
- **内容分离**: 严格区分需要翻译和不需要翻译的内容
- **位置保持**: 确保翻译后内容在原始位置正确重组

### 5.2 灵活的扩展性

- **可配置的过滤规则**: 通过配置文件调整 Front Matter 处理
- **正则表达式驱动**: 可以轻松添加新的跳过模式
- **节点系统**: 支持添加新的内容类型节点

### 5.3 语言特定优化

- **符号宽度处理**: 自动处理中文全角和英文半角符号
- **空格分隔优化**: 为非紧凑型语言添加适当的空格
- **标点符号智能处理**: 保持各语言的标点符号使用习惯

## 6. 总结

Free-Markdown-Translator 的过滤器系统采用了多层次的设计模式：

1. **正则表达式层**: 基础的文本模式匹配
2. **节点系统层**: 语义级别的内容分类
3. **翻译执行层**: 运行时的动态过滤

这种设计确保了：
- 翻译质量: 只翻译需要翻译的内容
- 格式完整性: 保持 Markdown 原始格式不变
- 性能优化: 避免翻译不必要的技术内容
- 可维护性: 模块化的设计便于扩展和维护

过滤器系统的核心思想是"分离关注点"——将格式标记、技术内容和自然语言文本严格分离，确保翻译过程中每个部分都得到恰当的处理。
