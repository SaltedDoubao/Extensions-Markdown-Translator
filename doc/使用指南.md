# 📚 Markdown Translator 使用指南

> 完整的插件安装、配置和使用教程

---

## 🚀 快速开始

### 第一步：安装插件

#### 方法一：VS Code扩展市场（推荐）
1. 打开VS Code
2. 按 `Ctrl+Shift+X` 打开扩展面板  
3. 搜索 "Markdown Translator"
4. 点击 **安装** 按钮

#### 方法二：从VSIX文件安装
1. 下载插件的 `.vsix` 文件
2. 在VS Code中按 `Ctrl+Shift+P` 打开命令面板
3. 输入 "Extensions: Install from VSIX"
4. 选择下载的 `.vsix` 文件

### 第二步：基础配置

1. 按 `Ctrl+,` 打开设置
2. 搜索 "Markdown Translator"
3. 配置您偏好的翻译引擎

## ⚙️ 详细配置说明

### 🔧 基础设置

#### 默认翻译引擎
```json
"markdownTranslator.defaultEngine": "google"
```

**可选值**:
- `"google"` - Google翻译（免费，无需配置）
- `"baidu"` - 百度翻译（需要API密钥）
- `"openai"` - OpenAI GPT（需要API密钥）
- `"claude"` - Claude AI（需要API密钥）

#### 自动过滤设置
```json
"markdownTranslator.autoFilter": true
```
**说明**: 自动跳过代码块、内联代码等不需要翻译的内容

#### 自动翻译设置
```json
"markdownTranslator.autoTranslateOnOpen": false
```
**说明**: 打开Markdown文件时是否自动翻译

### 🔑 API密钥配置

#### 1. 百度翻译配置

**获取步骤**:
1. 访问 [百度翻译开放平台](https://fanyi-api.baidu.com/)
2. 注册账号并创建应用
3. 获取 APP ID 和密钥

**配置方法**:
```json
"markdownTranslator.baiduAppId": "你的APP_ID",
"markdownTranslator.baiduSecretKey": "你的密钥"
```

#### 2. OpenAI配置

**获取步骤**:
1. 访问 [OpenAI API](https://platform.openai.com/)
2. 注册账号并获取API密钥
3. 确保账户有足够余额

**配置方法**:
```json
"markdownTranslator.openaiApiKey": "sk-你的OpenAI密钥"
```

#### 3. Claude配置

**获取步骤**:
1. 访问 [Anthropic Console](https://console.anthropic.com/)
2. 注册账号并获取API密钥

**配置方法**:
```json
"markdownTranslator.claudeApiKey": "你的Claude密钥"
```

## 📖 使用方法详解

### 🎯 方法一：命令面板操作

1. 打开Markdown文件
2. 按 `Ctrl+Shift+P` 打开命令面板
3. 输入以下命令之一：

| 命令 | 功能 | 适用场景 |
|------|------|----------|
| `翻译为英文` | 将整个文档翻译为英文 | 中文文档 → 英文 |
| `翻译为中文` | 将整个文档翻译为中文 | 英文文档 → 中文 |
| `翻译选中文本` | 翻译选中的文本片段 | 部分翻译 |
| `自动翻译当前文档` | 自动检测语言并翻译 | 智能翻译 |

### 🖱️ 方法二：右键菜单操作

1. 在Markdown文件中**选中**要翻译的文本
2. **右键**点击选中的文本
3. 选择 **"翻译选中文本"**

### 🔘 方法三：编辑器标题栏

1. 打开Markdown文件
2. 点击编辑器标题栏的 **翻译图标**
3. 自动翻译整个文档

## 💡 使用技巧和最佳实践

### 🛡️ 智能内容保护

插件会自动跳过以下内容，确保格式不被破坏：

#### ✅ 自动跳过的内容
```markdown
# 这些内容会被自动保护：

​```javascript
// 代码块不会被翻译
const code = "保持原样";
​```

这是一段包含 `内联代码` 的文本

![图片描述](image.jpg) 
<!-- 图片URL不翻译，但alt文本会翻译 -->

[链接文本](https://example.com)
<!-- 链接URL不翻译，但链接文本会翻译 -->

<div class="html">HTML标签不翻译</div>
```

#### 📝 格式保持
```markdown
# 原始格式：
# 这是标题
- 列表项目1
- 列表项目2
> 这是引用

# 翻译后格式：
# This is a title
- List item 1  
- List item 2
> This is a quote
```

### 🔍 智能语言检测

#### 自动检测逻辑
- **中文字符 > 30%** → 翻译为英文
- **中文字符 ≤ 30%** → 翻译为中文

#### 手动指定语言
如果自动检测不准确，可以使用指定命令：
- `翻译为英文` - 强制翻译为英文
- `翻译为中文` - 强制翻译为中文

### ⚡ 性能优化建议

#### 1. 选择合适的翻译引擎

| 场景 | 推荐引擎 | 原因 |
|------|----------|------|
| 日常使用 | Google | 免费、快速、无需配置 |
| 专业文档 | 百度/OpenAI | 准确度更高 |
| 技术文档 | OpenAI/Claude | AI理解上下文更好 |
| 大量翻译 | 百度 | 有配额但稳定 |

#### 2. 批量翻译技巧
- **小文档**（< 1000字）：直接整文档翻译
- **大文档**（> 1000字）：分段选择翻译
- **混合语言**：使用选择翻译功能

#### 3. 网络优化
- 确保网络连接稳定
- 如遇超时，可切换翻译引擎
- 大文档建议分段处理

## 🔧 常见问题解决

### ❌ 问题1：翻译失败
**症状**: 提示"翻译失败"错误

**解决方案**:
1. **检查网络连接**
   ```bash
   ping google.com  # 测试Google翻译
   ping fanyi-api.baidu.com  # 测试百度翻译
   ```

2. **验证API配置**
   - 检查API密钥是否正确
   - 确认账户余额是否充足
   - 验证API权限是否正常

3. **切换翻译引擎**
   - 临时切换到Google翻译
   - 检查其他引擎是否正常

### ❌ 问题2：部分内容未翻译
**症状**: 某些文本保持原文不变

**原因分析**:
- 可能被识别为代码块或特殊格式
- 文本包含特殊字符或标记

**解决方案**:
1. **检查文本格式**
   ```markdown
   # 这些可能不会翻译：
   `被误识别为代码的文本`
   <被误识别为HTML的文本>
   ```

2. **使用选择翻译**
   - 手动选中未翻译的文本
   - 使用"翻译选中文本"功能

### ❌ 问题3：格式丢失
**症状**: 翻译后Markdown格式混乱

**解决方案**:
1. **启用自动过滤**
   ```json
   "markdownTranslator.autoFilter": true
   ```

2. **检查文档结构**
   - 确保代码块有正确的三个反引号
   - 检查列表和标题格式是否标准

### ❌ 问题4：API配额用完
**症状**: 提示API请求过于频繁或配额不足

**解决方案**:
1. **临时切换引擎**
   ```json
   "markdownTranslator.defaultEngine": "google"
   ```

2. **查看API使用情况**
   - 百度翻译：登录控制台查看调用量
   - OpenAI：查看账户余额和使用情况

3. **等待配额重置**
   - 百度翻译：每月重置
   - OpenAI：根据计费周期重置

## 🔒 安全和隐私

### 🛡️ 数据安全

**API密钥保护**:
- 不要在公共仓库中提交密钥
- 定期更换API密钥
- 使用环境变量存储敏感信息

**文档隐私**:
- 敏感文档建议使用本地翻译引擎
- 了解各服务商的数据处理政策
- 避免翻译包含机密信息的文档

### 🔐 最佳实践

1. **密钥管理**
   ```json
   // 推荐：使用VS Code设置
   "markdownTranslator.openaiApiKey": "从环境变量读取"
   
   // 不推荐：直接在代码中暴露
   const apiKey = "sk-明文密钥";
   ```

2. **权限控制**
   - 定期检查API密钥权限
   - 监控API使用情况
   - 及时撤销不需要的访问权限
