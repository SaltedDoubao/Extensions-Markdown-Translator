# Change Log

All notable changes to the "markdown-translator" extension will be documented in this file.

## [Unreleased]

## [0.0.1] - 2025-09-16

### Added
- 初始版本发布
- 支持多种翻译引擎：Google翻译、百度翻译、OpenAI、Claude
- 智能markdown内容过滤，自动跳过代码块、内联代码、链接等
- 支持中英互译，自动检测文档语言
- 提供多种翻译命令：
  - 翻译为英文
  - 翻译为中文  
  - 翻译选中文本
  - 自动翻译当前文档
- 集成右键菜单，操作便捷
- 支持批量翻译处理
- 可配置自动翻译选项
- 完整的错误处理和用户反馈

### Features
- **Multi-engine Support**: Google Translate, Baidu Translate, OpenAI, Claude
- **Smart Filtering**: Automatically skip code blocks, inline code, links, etc.
- **Intelligent Translation**: Auto-detect document language and translate accordingly
- **Batch Processing**: Support for translating entire documents
- **Context Menu Integration**: Easy access through right-click menu
- **Configurable Settings**: Customizable translation engines and options
- **Format Preservation**: Maintain markdown structure during translation

### Configuration
- Default translation engine selection
- API key management for premium services
- Auto-translation settings
- Content filtering options
